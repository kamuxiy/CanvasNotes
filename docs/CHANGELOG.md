## [1.2.0] - 2026

### 新增

- Figma 暗色主题配色与可读性调整
- 节点连接点改为**底部条带**；「只允许连线从底部节点连接」
- 类型色描边（后改为更细、半透明）；字体对齐 Figma（Inter）
- 7 项 UX 打磨：水平拖宽、右键菜单行为、节点管理、dock 图标、文本高度自适应、菜单外关闭、适应避开底栏
- 满宽装饰进度条；日期控件默认日期类端口；布局/尺寸工作区持久化；控件右键「控件操作」

### 修复

- 节点管理点击无反应（改为 modal / 更稳妥的打开路径）
- 文本框需先下拖才能左右拖等问题
- 右键误弹删除确认、点击控件外菜单不消失

### 变更

- 多次在「侧边端口 / 底部端口 / 仅保留配色 / 还原 1.2.0」之间对齐用户预期后定稿：**Figma 配色 + 底部端口 + Upload Labs 节点铬**

## [1.1.0] - 2026

## [1.0.0] - 2026

### 新增

- 首版画布笔记：便签 / 日期 / 列表；ComfyUI 风格端口与贝塞尔曲线
- Electron 桌面客户端与自绘标题栏（无系统边框）
- Upload Labs 风格卡片与底部工具栏（由顶栏迁出）
- 连接规则：红色**通用**可连任意类型；多连；**左↔右**跨卡；禁自连与同侧
- GitHub 仓库、README（含配图）、Windows portable / Setup 与 Actions Release

### 修复

- 画布拖动无反应
- 端口标签对齐与卡片内容溢出
- 顶栏窄窗溢出 → 「更多」菜单（后整体改为底栏）

### 约束（用户原话摘要）

> 「我想要的是一个客户端应用，不是 web 应用」→「使用 exe 运行，有独立客户端，不使用浏览器来使用的样式」
>
> 「连线方式还是使用之前的曲线连接」
>
> 「红色通用节点可以连接任意颜色节点……只允许左侧节点连接其他卡片的右侧节点……」
