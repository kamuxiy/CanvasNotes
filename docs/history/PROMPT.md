## 产品愿景

- 制作一个**笔记 / 待办事项**软件，主要功能类似画布或白板（类似 Miro）。
- 连线方式**不要** Miro / 流程图样式，而使用类似 **ComfyUI** 的样式。
- 界面 UI 参考 ComfyUI，但仅作为笔记/待办软件，**不是**生图控制。
- 语言与框架任意；尽可能**轻量化**；界面简洁干净。
- **不使用系统标题栏**，重写软件边框。
- 要的是**客户端应用**，不是 Web 应用；进一步明确为可 **exe 运行**的独立客户端，**不使用浏览器**来使用。
- 卡片样式应类似游戏 **Upload Labs**（后续多次对照游戏内截图校正节点形状与连接位置）。

---

## 节点 / 连线规则

- 各组件可在侧边新建**自定义连接点**，连接点可自定义命名；**只允许连接点之间连线**。
- 节点类型可选：
  - 相关事件（连接便签/记事本）
  - 日期（连接开始日期/截止日期）
  - 相关信息（连接列表）
- 后续补充：**卡片初始节点类型改为通用（红色）**。
- 「红色通用节点可以连接任意颜色节点，所有节点可以连接多个其他节点」；「只允许左侧节点连接其他卡片的右侧节点，或者右侧节点连接其他卡片的左侧节点」；「卡片自己连接自己或者左侧连接左侧 / 右侧连接右侧是不允许的」。
- 连线方式保持此前的**曲线连接**（ComfyUI 曲线），不要改成正交折线。
- 节点名称与位置对齐：「比如右侧节点的名字需要右对齐显示在节点旁边」。
- 「卡片的内容不要超出卡片，左侧节点名称应该在节点右侧，右侧节点名称应该在节点左侧」。
- 后续纠偏：节点曾误放在卡片外侧；右侧名称曾再次错到卡片左侧——要求显示在**节点旁边左侧**。
- **Figma 暗色迭代后**：保留配色；「不是，仅修改节点样式，只允许连线从**底部节点**连接。其他可以使用之前参考 figma 的样式」；「节点样式和之前一样放在最下面」。
- 日期控件：「默认左右节点类型改为日期」。

## UI / UX

- 「顶部按钮在改变窗口大小后会超出按钮范围，改变窗口不要改变按钮大小，若按钮超出窗口大小则收起到下拉菜单」。
- 「卡片没有单独删除选项，将顶部选项改为类似 uploadlabs 类似的**底部菜单**，在选中卡片后显示额外选项（删除、复制等）」。
- 「整个软件界面还是有点不太可读，参考一下 **figma 暗色模式**下的主题，生成这个项目的预览给我看一下」。
- 「保留这个配色，节点显示逻辑还是使用之前的样式（控件底部显示节点与名称、节点编辑等）」并再出预览。
- 中间多次要求：**还原节点样式 / 仅保留配色 / 还原回 1.2.0**，再在 1.2.0 基础上继续功能与视觉微调。
- 「和 figma 一样加个对应颜色的控件边框，所有字体也复用 figma 的」；「边框细一点，颜色调稍微透明一点」。
- 控件顶部进度条：「改为始终满的装饰」；去掉日期/便签/列表顶部输入标题上部「带方框的一行内容」（如信息列表的列表标题），**不要删除输入框**。
- 右键控件：「显示右键菜单，内容显示编控件操作相关内容」；空白处右键主要为新增控件。
- **7 项 UX 优化**（原文）：
  1. 文本框拖动现在需要先往下拖一下才能左右拖，修复一下
  2. 右键控件只显示菜单，不要提示是否删除节点
  3. 右键控件菜单点击节点管理无反应
  4. 底部菜单栏各个选项都需要有图标
  5. 所有文本框高度自适应，需要始终显示完整内容，宽度初始使用默认宽度，用户可以拖动来更改宽度，同时高度自适应
  6. 右键菜单在点击菜单以外位置时需要消失，现在点击控件不会消失
  7. 适应功能需要考虑底部菜单栏位置，现在有部分控件会被菜单栏遮挡

## 工具栏 / Dock

- 顶部工具 → Upload Labs 风格**底部悬浮菜单**。
- 下方可切换鼠标操作类型：**选择** / **框选**；选择同前；框选拖出半透明方框多选控件（**不会选择连线**，连线自动适应控件位置）；框选完成后**自动切回选择**。
- 选中控件后底部增加操作（删除、复制、+左/+右、节点管理等）。
- 窄窗口时底栏按分组收起为「鼠标、新建、控件操作、工作区」等，点击后上方下拉展开。
- 底栏增加**设置**入口 → 浮窗左侧侧边栏分类；「关于」页含项目名、作者、技术栈版本、GitHub、当前版本；「检查更新」对照 GitHub Release；无网络显示「无网络」。
- 「每次添加新功能后推送到 GitHub 要同步更新 readme」。

## 工作区

- 下方新增工作区切换：可切换与新建不同工作区；文件保存在本地；允许打开/导入已有工作区；显示最近使用。
- 点击底部「工作区」显示工作区操作菜单。
- 拖动文本框大小、改变控件位置后**工作区需记住**，下次打开保持一致。

## 组件

- 初始组件类型：便签/记事本；开始日期/截止日期；列表（信息列表）。
- **分组控件**：点击生成半透明背景 + 上方不透明标题栏；点标题栏显示四边拖动手把改大小，点别处手把消失；初版要求在所有控件底层，组内控件跟随拖动；底部可改颜色（取色参考 Upload Labs）。
- 分组后续修订：标题重命名移到底部菜单；拖动时仅「开始拖动时已在组内」的控件跟随（过程中新进入的不跟随）；改为半透明遮罩在**所有控件上方**，鼠标可穿透点击内部控件；标题栏颜色为控件色降透明度。
- **Markdown**：支持 Markdown；自动识别一级标题为组件标题；编辑/预览。
- 便签等文本框大小支持上下左右拖动；其他文本输入同样。
- 「控件的文本输入框（markdown、便签、列表）左右拖动变大时控件不会一起变大，修复一下」。
- 「新建一个控件后，控件窗口会一直自动加宽」——需修复自动加宽循环。

## Bugs / 修复（用户提出）

- 鼠标拖动画布没有反应。
- 有时候点击便签的输入框无法输入内容；后续仍反馈「还是点击无法编辑控件内容」。
- Markdown 控件清晰度明显低于其他控件。
- 构建错误（BottomDock 模板字面量/未闭合标签；NodeCard `PLACEHOLDER`、隐式 any、导出缺失等）——用户贴出构建窗口报错要求修复。
- 节点管理从右键打不开；右键误弹删除确认；右键点控件外不消失；适应被底栏遮挡；水平拖宽需先下拖；新建节点无限加宽。
